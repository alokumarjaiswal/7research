# 7research
7th semester research repository for Final Year Major Project, 2025.

## Overview
This repository serves as a starter template for research project: ***Cross-Runtime Performance and Cost-Efficiency Analysis of AWS Lambda SnapStart: Structural Decomposition, Concurrency Behavior, and SLO-Aware Optimization.***.
Root files (such as PDFs, TEX documents, and images) can be directly modified and tracked here. We will use Overleaf for collaborative LaTeX editing and compilation. This repository is primarily for version control and reference.

## Templates
The `templates/` folder contains reference materials, including:
- IEEE paper format templates (DOCX and LaTeX).
- Conference LaTeX templates with associated files (e.g., IEEEtran.cls, BST files).
- Bibliography examples and HOWTO guides.

Use these as references but do not modify them directly; copy to the root if needed for your project.
